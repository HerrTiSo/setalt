# SetAlt — Setapp Alternatives

> Free, open-source, and subscription-free alternatives to popular [Setapp](https://setapp.com/) apps for macOS.

SetAlt is curated, not exhaustive. Alternatives should replace the main use case of a Setapp app, not just share a feature or two.

## Legend

| Symbol | Type | Meaning |
|:---:|---|---|
| 🟢 | **Open Source** | Available under an open-source license |
| 🔵 | **Free** | Free to use, but not necessarily open source |
| 🟡 | **One-time Purchase** | Paid, but no recurring subscription required |

**⭐ SetAlt Pick** — Our default recommendation when there's more than one good option.

> [!NOTE]
> Some apps fit more than one category. When comparable options exist, open source is preferred.

## What belongs on SetAlt?

An alternative should cover the main use case of a Setapp app and be available without a recurring subscription.

We prefer apps that are:

- actively maintained
- native or well integrated with macOS
- clear about pricing and licensing
- open source, where a good open-source option exists

Alternatives don't need to be clones. A different approach is fine if it solves the same problem well.

### What doesn't belong?

- subscription-only apps
- abandoned projects
- libraries or frameworks that aren't usable apps
- apps with only a superficial overlap
- general Mac app recommendations without a Setapp counterpart
