# Contributing to SetAlt

Thanks for helping keep SetAlt useful.

SetAlt is curated rather than exhaustive. A new entry should be a good subscription-free alternative to an app available through Setapp, not simply another Mac app in the same general category.

## Suggesting an alternative

Before submitting one, check that it isn't already listed or being discussed in an existing issue.

A good candidate should:

- cover the main use case of a Setapp app
- work well on macOS
- be actively maintained
- be open source, free, or available as a one-time purchase
- not require a subscription for its core functionality

Alternatives don't have to work exactly like the original. Different approaches are welcome when they solve the same problem well.

If there are important trade-offs, mention them.

## Types

| Symbol | Type |
|:---:|---|
| 🟢 | Open Source |
| 🔵 | Free |
| 🟡 | One-time Purchase |

If an app fits more than one type, prefer 🟢 Open Source.

## Pull requests

Use the existing table format:

| **Setapp App** | [Alternative](https://github.com/example/project) | 🟢 | Short, factual description |

Please:

* link directly to the GitHub repository for open-source projects
* otherwise link to the official project website
* keep descriptions short and factual
* mention important limitations
* don’t use affiliate or referral links

## Curation

More isn’t necessarily better.

Multiple alternatives are useful when they serve different kinds of users — for example GUI vs. CLI, simple vs. feature-heavy, or manual snapping vs. automatic tiling.

We don’t need five nearly identical options for the same app.

## Corrections

Please open an issue if an app:

* introduces a subscription
* changes its license
* is no longer maintained
* has a broken link
* is described incorrectly
* no longer makes sense as an alternative

Removals and corrections are just as useful as new entries.

## Conduct

Be constructive toward developers and other contributors.

SetAlt is about finding alternatives, not attacking commercial software or the people who make it.
